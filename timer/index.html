このタイマーについて

時間を「見る」。進行を「共有する」。

このタイマーは、研修講師・ファシリテーターとして活動している製作者（てつお）が、「自分自身が使いやすいタイマーが欲しい」という思いから開発したものです。

研修やワークショップで実際に時間管理を行う中で感じた、さまざまな「あったらいいな」を少しずつ形にしてきました。

もともとは自分自身のために作ったツールですが、せっかくなので、同じような場面で役立てていただければと思い、一般公開しています。ご感想や改善要望などいただけますととても励みになります^^

POMODORO 集中と休憩のサイクル

🍅 ポモドーロテクニック

短時間の集中と休憩を繰り返し、生産性を高める時間管理術です。1980年代にイタリアのフランチェスコ・シリロが考案しました。「ポモドーロ」はイタリア語でトマト。愛用していたトマト型キッチンタイマーが名前の由来です。

集中力が切れる前に休憩を挟むことで脳の疲労（バーンアウト）を防ぎ、「あと10分」という適度な時間意識が作業効率を自然に引き上げます。

    （任意）
  2. 25分間
    集中する
  3. 5分間
    休憩する
  4. 4回後に
    長く休む
