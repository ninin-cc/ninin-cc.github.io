# Workshop Timer Overlay

PowerPointのスライドショー上に重ねて使える、背景透明のワークショップタイマーです。

## 2つの使い方

### Windows透明オーバーレイ版（推奨）

PowerPointの背面を透かして表示するには、Electron版を使用します。通常のブラウザはウインドウ自体を透明にできないため、`index.html` をブラウザで開くだけではPowerPointまでは透けません。

GitHubへpushすると、`.github/workflows/build-windows.yml` がポータブルEXEを自動生成します。

1. GitHubのリポジトリを開く
2. `Actions` → `Build Windows App` → 最新の実行結果を開く
3. `Artifacts` の `workshop-timer-windows` をダウンロード
4. ZIPを展開し、`Workshop-Timer-Overlay-1.0.0-x64.exe` を起動

署名していない個人配布用アプリのため、Windows SmartScreenが警告を表示する場合があります。配布元とファイルを確認したうえで使用してください。

### ブラウザ版

`index.html` を開くだけで通常のタイマーとして使用できます。GitHub Pages用のワークフローも同梱しています。初回のみリポジトリの `Settings` → `Pages` → `Source` を `GitHub Actions` に設定してください。

Google Analytics 4（測定ID `G-Z1T35THNDV`）を設定済みです。GitHub PagesなどのHTTP/HTTPS公開時だけ計測し、ローカル版とElectron版は計測しません。

## ローカルでElectron版を起動

Node.jsをインストールした環境で次を実行します。

```powershell
corepack enable
pnpm install
pnpm start
```

Windows用ポータブルEXEを手元で作る場合：

```powershell
pnpm run dist:win
```

## グローバルショートカット

Electron版では、PowerPointを操作中でも以下のキーが使えます。

| キー | 動作 |
| --- | --- |
| `Ctrl + Shift + Space` | タイマー開始／一時停止 |
| `Ctrl + Shift + T` | クリック透過／操作可能を切り替え |
| `Ctrl + Shift + H` | 操作パネルを表示／非表示 |
| `Ctrl + Shift + R` | 最後にセットした時間へリセット |
| `Ctrl + Shift + F` | 全画面表示を切り替え |
| `Ctrl + Shift + Q` | アプリを終了 |

クリック透過を有効にすると、マウス操作は背面のPowerPointへ届きます。アプリを再び操作するには `Ctrl + Shift + T` を押してください。

## 主な機能

- 背景が完全に透明な最前面ウインドウ
- 1・3・5・6・10・15分のプリセット
- 時・分・秒の手動設定
- 時間追加、直前の追加を戻す、開始、一時停止、リセット、クリア
- プリセット／時間追加と手動設定欄の連動、手動入力の即時プレビュー
- プリセット＋ADD、タイマー＋休憩、表示設定を常時表示する3段のコンパクト設定UI
- カウントダウンとストップウォッチを独立した開始ボタンで切り替え
- カウントダウンの秒更新をアナログ時計の秒針と同期
- タイマー実行中はアナログ時計の太線横に「終了」を表示
- TIMER・BREAKの設定変更を、開始前からアナログ時計の「終了」「再開」位置へ即時反映
- VIEWの「数字文字盤」で、アナログ時計の1〜12表示を切り替え（初期設定はオフ）
- BREAKの「10分」「60分」で現在時刻から設定し、「＋1」「−1」で1分単位に調整
- ポモドーロテクニックモード（任意のタスク入力、25分集中、5分休憩、4回後の15・20・30分休憩、サイクル進捗）
- VIEWからデジタル時計を非表示にし、背景のアナログ時計だけを表示可能
- ボタン下のアコーディオンで、ワークショップ・研修・学習での活用方法を案内
- 実行中のADDはYES／NO確認後、現在の残り時間へ加算
- ストップウォッチは1/100秒まで表示し、表示中はアナログ時計の秒針を一時的に非表示
- 終了チャイムと赤色点滅
- 指定した再開時刻を「休憩中／13:20／再開」のオーバーレイで表示
- アナログ時計に休憩時間を扇形で表示し、再開時刻を太線、1時間以上を時間ラベル付きで明示
- 休憩終了時のチャイムと休憩表示の自動解除
- 現在時刻を示すアナログ時計
- 境界バーによる時計幅・表示部高さの調整と位置保存
- ウインドウを小さくしても表示部と設定部の境界バーを常に表示
- ウインドウを縦に縮めた際は表示部の高さを維持し、設定部のみ縮小
- 操作パネル、時計、テーマ、背景時計濃度の切り替え
- 初期表示はライトテーマ（ダークテーマへ切り替え可能）
- ブラウザ版とWindowsアプリ版の両対応
- 画面右下からいつでも開ける、初心者向けの体験型チュートリアル
  - プリセット、タイマー開始・停止、停止中ADDと取り消し、実行中ADDと延長確認を実際に操作
  - 練習終了時に、開始前のタイマー状態へ自動で復元
